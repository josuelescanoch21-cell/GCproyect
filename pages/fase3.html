    ⚙️ Arquitectura de Seguridad — RBAC

    Capa 1 — Autenticación

    Token de sesión + Hash de contraseña

    En producción: bcrypt para hashing de contraseñas, JWT firmado para tokens de sesión con expiración de 8 horas. Refresh token almacenado en cookie HttpOnly para prevenir XSS.

    ↓
    Capa 2 — Autorización RBAC

    Control de Acceso Basado en Roles

    Cada ruta y acción verifica el rol del usuario antes de ejecutarse. Los permisos están definidos en una matriz centralizada: Administrador hereda todos los permisos de Editor y Lector.

    ↓
    Capa 3 — Auditoría

    Historial inmutable + Diff View

    Cada acción (crear, editar, eliminar, cambiar rol) queda registrada con timestamp, usuario, IP y detalle del cambio. El diff view muestra exactamente qué texto fue modificado entre versiones.
